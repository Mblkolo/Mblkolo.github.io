# 🔤 Английские буквы — тренажёр для ребёнка

Приложение на чистом HTML + CSS + JavaScript (без сборки, без зависимостей, работает офлайн).
Ребёнок учит все 26 букв английского алфавита: узнаёт букву и называет её, угадывает букву по звуку.

## Как запустить

Просто открой `index.html` двойным щелчком в браузере (Edge, Chrome, Яндекс). Сервер не нужен.
Можно выложить на GitHub Pages — адрес будет вида
`https://Mblkolo.github.io/english-letters/`.

Звук — через браузерную озвучку (Web Speech API). В Edge и Chrome английские голоса есть из коробки;
если звука нет — выбери голос в «⚙️ Настройки».

## Механика: карточка из двух половин

```
┌────────────────┐ ┌────────────────┐
│  ЗАДАНИЕ       │ │  ОТВЕТ (скрыт) │   ← на широком экране рядом,
│  B b   или 🔊  │ │  🎁 показать   │     на телефоне — одна под другой
└────────────────┘ └────────────────┘
        [ ✔ Правильно ]   [ ✖ Неправильно ]
```

1. Слева (на телефоне — сверху) задание: буква **или** звук буквы (озвучка + кнопка 🔊).
2. Правая половина — ответ, он закрыт. Чтобы открыть, нужен **отдельный клик** по половине
   или по кнопке «Показать ответ 👀». Сначала ребёнок вспоминает сам, потом проверяет себя.
3. После открытия появляются две кнопки: **✔ Правильно** и **✖ Неправильно** — это и есть статистика.
   Никакого обмана: пока не открыл ответ, кнопки неактивны.
4. «Следующая карточка →» … в конце — результат, «Ещё раз те же буквы» или «📚 Новое упражнение».

Режимы (кнопки на главной): **👁️ Читаю** (буква → название), **✍️ Пишу** (звук → буква),
**🔀 Смешанно** (оба навыка вперемешку, по 2 карточки на букву).

Отдельного «взрослого» и «детского» режима нет. Есть только **🃏 Посмотреть все буквы** —
те же карточки со скрытым ответом, но без кнопок «правильно/неправильно»: чистый просмотр,
статистика не меняется.

## Правила отбора букв

* **Первый день — 1 буква.** Дальше каждый календарный день добавляется **одна новая** буква, всего до 5 в упражнении.
* Порядок введения: `S A T I P N E M D O R C G B H F L U Y Q W X Z K V J` (сначала самые частые) — правь массив `INTRO_ORDER` в `letters.js`.
* Буквы с ошибками возвращаются чаще: «вес слабости» = ошибки × 3 + недавняя ошибка (×2, если в последние 7 дней) + давность повторения + чуть-чуть за число попыток. Берутся 4 самых тяжёлых.
* Успешные буквы тоже повторяются — ни одна не исчезает.
* Новая буква приходит **на следующий день**, поэтому сколько бы раз ты ни занимался сегодня,
  вторую новую букву в тот же день не получишь. Если повторять уже нечего — карточки делают из сегодняшних букв.

## Статистика (вся в localStorage)

Ключ `engLtr.v1`:

```jsonc
{
  "letters": { "A": { "c": 3, "w": 1, "lastWrong": "2026-11-20", "lastSeen": "2026-11-20" } },
  "daily":   { "2026-11-20": { "sessions": 2, "used": ["S","A"] } },
  "order":   { "S": 1, "A": 2 },           // порядок введения букв
  "streak":  { "count": 5, "last": "2026-11-20" },
  "settings":{ "sound": true, "voiceURI": null, "rate": 0.9 }
}
```

На главной видно: сколько букв изучено, сколько дней подряд, сколько занятий сегодня и ленту всех 26 букв
(🟩 выучено, 🟧 «хромает», 🟨 новая буква дня, 🟦 попадёт в следующее упражнение).

«💾 Скачать файл» / «📂 Загрузить файл» — перенос прогресса на другое устройство или запасная копия перед чисткой браузера.

## Клавиатура (на компьютере)

| клавиша | действие |
|---|---|
| Пробел / Enter | открыть ответ, затем — следующая карточка |
| `1` | ✔ Правильно |
| `0` | ✖ Неправильно |
| ← → | листать буквы в просмотре |

## Файлы

| файл | что внутри |
|---|---|
| `index.html` | экраны: главная, запись упражнения, карточка, результаты, просмотр, настройки |
| `style.css`  | крупный детский интерфейс, карточка из двух половин с закрытым ответом |
| `letters.js` | 26 букв: название по-русски, звук, слово-пример, эмодзи; порядок введения; тексты для озвучки |
| `app.js`     | хранилище, отбор букв, карточки, озвучка, статистика, экспорт/импорт |

## Что подкрутить под себя

* число букв в упражнении — `MAX_PER_DAY` в `app.js`;
* порядок и названия букв — `letters.js`;
* скорость речи — в настройках (по умолчанию 0.9).
